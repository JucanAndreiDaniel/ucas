## Takeaway
Core table/lookup semantics (out-of-range = undefined, index coercion, mixed element-type promotion, `find` packed constants, BC4/BC5 texenc decodes) are sound and deterministic; the only gap is that a table-of-tables cannot be indexed twice when the first index is a runtime value.
